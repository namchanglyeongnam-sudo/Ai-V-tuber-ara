# AI 버튜버 '아라' (프로토타입)

대본과 시청자 채팅에 반응하는 AI 버튜버입니다. Claude가 대사를 만들고, 음성(TTS)과 VTube Studio 아바타의 표정·모션·립싱크로 말합니다.
소프트웨어 공학 수업의 **프로토타이핑 모델**로, AI와 함께 만들고 써 보며 고쳐 나간 과정을 담았습니다.

- 설계 문서: https://claude.ai/artifact/CHwHcBEwNaD9S1EabAydBC
- AI 활용 사례: https://claude.ai/artifact/9f5YJ13B88MPegZKYdSiSA

## 수업 연계

창업 아이디어 발표에서 구상한 서비스는 **제품이나 브랜드를 홍보하며 시청자에게 흥미와 정보를 주는 AI 챗봇**입니다. 이를 한 번에 만들지 않고, 바탕이 되는 캐릭터 대화를 첫 프로토타입으로 먼저 만들었습니다. 써 보며 부족한 점(모션 길이, 립싱크, 부적절한 입력 대응)을 추가해 개선했고, 제품 정보 연동은 다음 과제로 남겼습니다.

**핵심 메시지**: AI 없이는 시도조차 못 했지만, AI는 만능이 아닙니다. 방향을 잡고 잘 묻고 직접 확인하는 사람이 필요했습니다.

## 주요 기능

- 대본 진행(Enter)과 시청자 채팅 애드립. 채팅이 들어오면 대본 위치를 유지한 채 잠깐 반응합니다.
- 답변 앞에 붙는 `[표정:이름]` 태그로 10가지 감정을 VTube Studio 표정·모션에 연결합니다.
- edge-tts 음성 출력, 소리 크기에 맞춘 립싱크, 말하는 동안 모션 반복(감정마다 `motion_extra.json`의 다른 모션으로 순환).
- 마이크 입력(`/mic`): 말한 내용을 글자로 바꿔 채팅과 같은 경로로 처리합니다.
- 방송 기억(`memory.json`), 호출별 토큰·비용 기록(`usage_log.csv`).
- 비용 절감: Haiku 5.5, 사고 끔, 페르소나 프롬프트 캐싱, 최근 대화 8개만 전송.
- 입력 방어: 페르소나 규칙과 채팅 정리(`clean_chat`, 길이 제한과 대괄호·따옴표 치환).

## AI 활용 방법과 프롬프트 예시

**방법**: 최소 기능(콘솔 대화)을 먼저 만들고, 써 보며 부족한 점을 한 가지씩 AI에게 요청했습니다. 도구·모델 선택과 기능 폐기는 사람이 결정했고, AI가 준 코드는 직접 실행해 확인했습니다.

**예시 1. 상황과 원하는 결과를 함께 말한 요청** (실제 요청을 간추림)

> TTS가 말하는 것에 비해서 모션이 너무 짧아. 모션은 2~3초 정도인데, 10초 정도 말하면 중간에 모션이 한 번 더 들어갔으면 좋겠어.

결과: 말하는 동안 5초마다 모션을 다시 재생하는 코드를 받았고, 실행해 반복되는 것을 확인했습니다.

**예시 2. 프로젝트 작업 규칙** (프로젝트 지침에서 간추림)

> 1. 한 번에 한 단계. 이전 단계가 실제로 확인되기 전에 다음으로 넘어가지 않는다.
> 2. 검증 수준을 구분해서 말한다: 자동시험 통과 / 실환경 확인 / 미확인. 실행하지 않은 것을 확인됐다고 하지 않는다.
> 3. 모르면 추측하지 말고 질문한다.
> 4. 답변은 짧게. 코드는 바뀐 부분만 준다.

**사람이 한 일, AI가 한 일**

| 장면 | 사람 | AI |
| --- | --- | --- |
| 방향 결정 | 도구·모델 선택, 기능 폐기 | 선택지와 영향 설명 |
| 구체적인 요청 | 상황과 원하는 결과를 말함 | 바로 쓸 수 있는 코드 제공 |
| AI의 실수 | 오류 전문을 붙여 넣음 | 코드 삽입 위치 안내가 모호해 오류가 났고, 파일을 보고 원인을 짚음 |
| 대기 중 움직임 | VTube Studio의 idle action 설정을 직접 찾아 해결 | 코드가 아니라 VTS 설정일 가능성으로 범위를 좁힘 |

## 실행 방법 (Windows, PowerShell)

준비물: 파이썬, Anthropic API 키, VTube Studio와 Live2D 모델, 인터넷.

```
python -m pip install -r requirements.txt
python -m pip install SpeechRecognition pyaudio      # /mic을 쓸 때만
$env:ANTHROPIC_API_KEY="본인_키"
```

1. VTube Studio에서 모델을 불러오고 설정의 `Allow Plugin API access`를 켭니다.
2. 처음 한 번, 모델의 표정·모션을 감정에 연결합니다. 허용 팝업이 뜨면 Allow를 누릅니다.
   ```
   python vts_client.py --map
   ```
3. 실행합니다.
   ```
   python vtuber_chat_test.py
   ```

입력창에서 Enter는 대본 진행, 글자 입력은 가짜 시청자 채팅, `/mic`은 마이크 입력, `/emo <감정>`은 표정 시험, `/vts`는 모델의 표정·핫키 목록, `/fix <지시>`는 말투 교정, `/skip`은 대본 건너뛰기, `exit`는 종료입니다.

**주의**
- `motion_extra.json`의 `hotkey:T1`~`T9`는 개발에 쓴 모델의 핫키 이름입니다. 다른 모델이라면 이 파일을 지우거나 본인 모델의 핫키 이름으로 고치세요.
- VTube Studio 없이도 대사는 나오고, 표정만 바뀌지 않습니다.

## 알려진 제한

- 제품 정보를 대본에 넣으면 전달할 수 있는 구조이지만, 정확히 전달되는지는 시험하지 못했습니다. 정해진 문장을 글자 그대로 읽는 기능은 없습니다.
- 모션이 재생되는 동안 립싱크가 일시적으로 묻힙니다. 모션 파일이 입 파라미터를 함께 움직이기 때문으로 추정하지만 확인하지는 못했습니다.
- 음성 인식(`/mic`)은 구글 웹 음성 인식을 쓰며, 인터넷이 필요하고 무료 사용 한도와 약관은 확인하지 못했습니다.
- Windows에서 개발하고 확인했습니다. 다른 컴퓨터나 운영체제에서의 설치와 실행은 확인하지 못했습니다.

## 아바타 크레딧

아바타는 VTube-Studio의 Live2D의 기본 제공 모델 **Hiyori**를 임시로 사용했습니다. 모델 파일은 이 저장소에 포함되어 있지 않습니다.
